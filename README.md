# Pratham Deepak — Portfolio

A custom React + Vite portfolio designed for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Create a GitHub repository, for example `pratham-portfolio`.
2. Push this project to the repository.
3. Open Vercel and import the GitHub repository.
4. Vercel will detect Vite automatically.
5. Deploy.

No environment variables are required.

## Important

- Replace the LinkedIn URL in `src/App.jsx` with your actual LinkedIn profile.
- `public/resume.pdf` is your current resume.
- Project links point to your public GitHub repositories.
